# VCStation 1.1.0

VCStation 1.1.0 完成了从 DualVideoStudio 到 VCStation 的产品迁移，并强化了
高刷新率多源播放、精确跳转、硬件解码、零拷贝呈现和退出可靠性。

## 发布验证

- Release 与 Debug 构建、全量测试、格式检查和静态分析通过。
- RTX 4090 物理显示输出上的 D3D11VA 与零拷贝测试通过。
- 三路 1080p60 连续运行五分钟，掉帧率为 0。
- 两路与三路 1080p120 各运行一分钟，掉帧率均为 0。
- 三项正式门槛的 seek P95 均低于 500 ms，UI 响应均低于 100 ms。
- 1.0.0 到 1.1.0 的 MSI 升级、packaged smoke 与 shutdown soak 由发布工作流
  在生成产物前执行。

## 已知限制

- 本版本的 ZIP、EXE 和 MSI 未进行 Authenticode 签名。Windows 可能显示
  “未知发布者”或 SmartScreen 提示；请只从本仓库的 GitHub Release 下载，并使用
  随附的 `SHA256SUMS.txt` 核对文件完整性。
- 三路 4K30 Main10 长时性能门槛延期，不属于 v1.1.0 的发布通过证据；相关测试入口
  保留，后续完成性能调优后恢复为阻断门槛。
