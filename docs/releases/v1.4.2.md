# VCStation 1.4.2

VCStation 1.4.2 是严格的 Bugfix 版本，修复持久化三路 Pair 在两路会话中让 Wipe/Diff
退化为黑屏的问题，并收口渲染失败、命中坐标、会话错误投影及发布回归门禁。

---

## 主要修复

- 比较模式和 Pair 现在由实际 Source 数量解析；两路会话始终向渲染器投递有效 A/B 状态，
  同时保留三路用户意图，以便第三路恢复时复用。
- Wipe 使用完整图像坐标和旋转后采样坐标；单侧缺帧只使该侧保持黑色，Difference 在选中
  Pair 缺帧时明确失败关闭，不会错误显示单路画面。
- ROI、Zoom/Pan、Letterbox 和 Wipe Handle 共用呈现几何，点击 Letterbox 不再被解释为视频
  内容坐标。
- 会话错误、Range Loop、缩略图异步结果、Marker 截断、输入焦点和 Info 面板的实际解码
  后端显示均已修复或补足可见反馈。
- GPU runner 新增真实 QML Wipe/Diff 像素捕获门禁；MSI 升级门禁覆盖 1.2.0→1.4.2，
  并验证保留的 Wipe/0-2 设置在两路中解析为 A/B。

---

## 发布范围

支持范围保持 H.264、HEVC、MPEG-4 Part 2 与 SDR 视频；音频轨道不会播放。发布产物为
Windows x64 ZIP、MSI 和 SHA256SUMS。该版本沿用仓库中明确的未签名发布边界：Windows
可能显示 Unknown Publisher 或 SmartScreen 提示，SHA-256 仅校验文件完整性。

发布仅在精确 tag/版本、Debug/Release、Quality、D3D11VA 硬件、性能、两条 MSI 升级、
packaged smoke 和 shutdown soak 都在目标 release SHA 上通过后创建 draft release。
