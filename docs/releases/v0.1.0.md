# DualVideoStudio 0.1.0

这是 DualVideoStudio 从双视频播放器迁移为 2～3 路 VFI 专用比较器后的首个可下载版本。
本版本发布自 `main`，USERPLAN 0～6 阶段的实现、自动化检查、真实硬件性能门禁和
Windows 发布包验证均已完成。

## 主要能力

- 支持 2 路或 3 路视频的帧精确同步审查，并明确选择 canonical/reference source。
- 每次显示均发布完整、原子的 `FrameSet`，不会混合不同请求或不同时间位置的帧。
- 支持任意两路差分、全局偏移估计、带状序列对齐、掉帧/重复帧检测和手动锚点。
- 对齐分析使用独立、可取消的作业与进度事件，不阻塞播放协调器。
- 每个来源使用持久解码 actor 和有界 mailbox；解码错误与真实缺帧保持不同语义。
- 差分边界缺帧时显示黑色，不再回退为单路原图。
- 支持同步缩放/平移、ROI、阈值遮罩、四面板分析网格和 exact-plane difference。
- 支持 8/10-bit、P010、YUV422/YUV444/RGB 视觉归一化、rotation、SAR 和颜色元数据。
- D3D11VA 与 Qt 共用一个 D3D11 设备，NV12/P010 decoder surface 直接进入 renderer，
  并保留软件回退原因和 device generation。
- Project schema v3 保存来源、offset、anchors、view state，并支持 GUI
  open/save/relink 和派生对齐缓存。
- Windows x64 ZIP 和 MSI 均捆绑固定版本的 FFmpeg/ffprobe 8.1.2、Qt 运行时、
  provenance 及第三方许可文本。

## 当前边界

- 性能门禁素材不进入 Git 仓库；runner 通过 `DVS_PERFORMANCE_FIXTURE_ROOT`
  提供六个 305 秒固定素材。
- presentation index 和 signature cache 当前为进程内复用；跨进程持久化可作为后续优化。
- 当前发布资产未进行 Authenticode 代码签名；Windows 可能显示 SmartScreen 提示，
  请使用随 Release 提供的 SHA-256 文件核验下载。
