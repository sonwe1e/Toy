# DualVideoStudio 0.1.0

这是 DualVideoStudio 从双视频播放器迁移为 2～3 路 VFI 专用比较器后的首个可下载版本。
本版本发布自 `refactor/unified-comparator` 分支，作为当前开发里程碑，不代表已合并到
`main` 或完成全部硬件性能目标。

## 主要能力

- 支持 2 路或 3 路视频的帧精确同步审查，并明确选择 canonical/reference source。
- 每次显示均发布完整、原子的 `FrameSet`，不会混合不同请求或不同时间位置的帧。
- 支持任意两路差分、全局偏移估计、带状序列对齐、掉帧/重复帧检测和手动锚点。
- 对齐分析使用独立、可取消的作业与进度事件，不阻塞播放协调器。
- 每个来源使用持久解码 actor 和有界 mailbox；解码错误与真实缺帧保持不同语义。
- 差分边界缺帧时显示黑色，不再回退为单路原图。
- Windows x64 ZIP 和 MSI 均捆绑固定版本的 FFmpeg/ffprobe 8.1.2、Qt 运行时、
  provenance 及第三方许可文本。

## 本地发布验证

- Debug：299/299 测试通过。
- Release：299/299 测试通过。
- `format-check` 和完整 `lint` 通过。
- Release 安装树中的 GUI/CLI 与构建产物 SHA-256 一致。
- 安装树、ZIP 解包目录和 MSI administrative image 的 CLI startup check 与 GUI smoke
  均通过。
- ZIP 与 MSI 通过统一的 FFmpeg 版本、provenance、许可、PE subsystem 和包内启动闸门。
- MSI 通过 WiX 4.0.4 数据库验证，并成功完成 administrative extraction。

## 当前边界

- D3D11VA 硬件解码、P010/10-bit 和规定的 1080p60 五分钟硬件性能门禁尚未完成。
- 长视频 signature/时间戳索引的磁盘缓存和进一步性能优化仍属于后续工作。
- 当前发布资产未进行 Authenticode 代码签名；Windows 可能显示 SmartScreen 提示，
  请使用随 Release 提供的 SHA-256 文件核验下载。
