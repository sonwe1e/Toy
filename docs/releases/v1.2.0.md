# VCStation 1.2.0

VCStation 1.2.0 expands the canonical FrameSet pipeline from comparison-only use into a 1～3 source
video workstation while retaining atomic presentation and explicit async identity.

---

## Highlights

- A single dropped video or `--play` request opens directly at the paused first frame; comparison
  and alignment controls disappear, while playback, seek, frame stepping, save, and restore remain.
- `--compare` accepts two or three Unicode paths. A recoverable per-user lock elects one primary;
  a bounded, acknowledged `QLocalServer` protocol forwards later launches and reuses the
  source-order/Reference confirmation dialog.
- `VCStationShell.dll` implements a lightweight `IExplorerCommand` for exactly two supported local
  videos. It uses `CreateProcessW` and links neither Qt nor FFmpeg.
- Project Schema v4 persists Single, Analysis Grid, Wipe, selected edge, filter, gain, threshold,
  viewport, and ROI, with deterministic v2/v3 migration.
- Wipe uses surface-normalized coordinates across letterbox, zoom, ROI, rotation, and DPI; its
  handle has a narrow 20×84 visible knob and a forgiving 52 px full-height hit area.
- Transport controls use a unified SVG icon set and fixed 1-frame, 5-frame, and 1-second semantics.
- The canvas-first shell keeps normal review controls compact. `Tab` hides all chrome, `F11`
  independently toggles native full screen, and shortcuts plus the Wipe handle remain active in
  the pure-canvas state with an 800 ms frame/playback HUD.
- Adding or removing a source pauses playback and rebuilds the 1–3 source session under a new
  epoch. The old canonical MediaTime is mapped onto the new timeline instead of reusing FrameId.

Release signing is fail-closed for the GUI, CLI, Shell DLL, and MSI. Checksums are calculated only
after signing. The active performance matrix contains 1080p60 and 1080p120 profiles; small P010
fixtures retain 10-bit correctness coverage without an active 4K profile.
