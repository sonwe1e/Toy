# VCStation 1.4.0

VCStation 1.4.0 收口为 Windows 上的 1～3 路静音视频播放与逐帧视觉审查工具。本版本不保存
Project 或 Bad Case，不播放音频，也没有新增 VP9、AV1、HDR 或进一步的 Alignment 能力。

---

## 主要变化

- 所有打开、追加、替换、Reference 切换和关闭请求经统一会话门面串行处理；忙碌期间的
  请求会排队并显示非模态反馈，不再静默丢失。
- 删除 Prediction-only 入口，canonical Reference 始终明确；空状态下 Compare、Analyze
  及右键菜单只暴露有效命令。
- 删除 Workspace 薄壳和 QML 中重复的 Active/Staged Source 真值；Renderer 与 ROI、Pan、
  Zoom 共用 `SurfacePanelLayout` 命中映射。
- `ApplicationMenuBar`、`ReviewShortcuts`、`ComparisonViewport` 和 `TabbedInspector` 使用显式
  输入/意图接口；In/Out 与循环区间状态由统一会话门面持有，不再散落在 `Main.qml`。
- 支持 1～3 个裸路径启动，以及 Explorer 中针对 1、2、3 个视频的动态命令。
- Shortcut preset 与 DF/NDF 偏好持久化；Settings completion 改为事件驱动。
- 单视频使用悬浮 Source Chip，OSC 可由视口鼠标移动和播放操作唤醒，Inspector 在窄窗口中
  以覆盖层显示，顶层菜单获得统一的 hover/focus 样式。
- MSI 在安装和升级时防御性清理旧 `.dvsproj`、`VCStation.Project` 与 SupportedTypes 注册。
- 性能矩阵新增独立的两路 1080p60 五分钟门禁。

---

## 媒体与发布范围

支持范围保持 H.264、HEVC、MPEG-4 Part 2 与 SDR 视频；音频轨道不会播放。发布产物包括
Windows x64 ZIP、MSI 和 SHA256SUMS。所有 EXE、DLL、ZIP 与 MSI 均不进行 Authenticode
签名，因此 Windows 可能显示 Unknown Publisher 或 SmartScreen 提示；SHA-256 仅校验文件
完整性。

发布 workflow 对精确 tag/版本、Debug/Release 测试、质量门禁、D3D11VA 硬件与性能门禁、
MSI 安装/1.1.0 升级、packaged smoke 和 shutdown soak 保持失败关闭。只有这些门禁在目标
release SHA 上全部通过后，draft release 才可转为正式发布。
