# VCStation 1.4.5

VCStation 1.4.5 是一次以模块边界、Windows UI 一致性和发布可靠性为重点的重构版本。
它保留现有 Clean Architecture 与完整 FrameSet 原子发布语义，同时拆分过度集中的应用、
组合根和展示职责。

---

## 主要变化

- 将播放、对齐、会话命令和展示契约拆分为更小的模块，收紧 Domain、Application、
  Windows、FFmpeg、持久化和 Qt UI 之间的依赖方向。
- 精简 `PlaybackCoordinator`、`ReviewRuntime`、`ReviewController` 与大型 QML 组件的职责，
  增加明确的运行时桥接、会话外观和消息目录。
- 统一菜单、工具按钮、提示框和主题颜色；工具提示保持不透明，Compare 菜单在双视频模式
  下不再保留隐藏行空白。
- Side by side、Wipe、Difference、Layout、Pair、Reference 和快捷键预设等互斥菜单统一
  使用圆形单选指示器，并保持键盘与辅助功能语义一致。
- 增加 Basic/Windows 风格及 100%、125%、150% 缩放下的菜单、提示框和响应式布局回归
  测试，同时强化架构、依赖和测试注册门禁。

---

## 发布范围

VCStation 支持 H.264、HEVC、MPEG-4 Part 2 与 SDR 视频，不播放音频轨道。发布产物为
Windows x64 ZIP、MSI 与 SHA256SUMS。本版本保持未签名：Windows 可能显示 Unknown
Publisher 或 SmartScreen 提示，SHA-256 仅用于校验产物完整性。

Draft Release 仅会在精确 tag/版本验证、Debug 与 Release 检查、Quality、D3D11VA 硬件和
性能门禁、1.2.0 升级、packaged smoke、shutdown soak，以及 FrameProvider 100 次资源退休
压力测试全部在目标 release SHA 上通过后创建。
