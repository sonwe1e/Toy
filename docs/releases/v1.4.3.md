# VCStation 1.4.3

VCStation 1.4.3 是补丁版本，交付既定的 Wipe/Diff 审查修复，并让 D3D11VA 发布门禁在
真实交互式用户环境中测量性能。

---

## 主要修复

- 两路 Wipe 与 Difference 依据当前 Source 数量解析 Pair；保留的三路偏好在两路会话中会
  投射为有效的 A/B 呈现状态。
- 播放协调器将短于两秒的 render-ack 调度停顿视为延迟而非丢帧，持续超时仍按原有语义受
  门禁约束；每次呈现继续只发布完整的 canonical FrameSet。
- D3D11VA 硬件与性能测试以 Normal 优先级和 runner 完整 CPU affinity 运行，配置与构建仍
  为 4 核 BelowNormal。门禁仍要求最多 0.5% 丢帧、500 ms cold-seek P95、100 ms 播放
  响应，并在性能 artifact 中记录实际启动配置。

---

## 发布范围

VCStation 支持 H.264、HEVC、MPEG-4 Part 2 与 SDR 视频，不播放音频轨道。发布产物为
Windows x64 ZIP、MSI 与 SHA256SUMS。本版本保持未签名：Windows 可能显示 Unknown
Publisher 或 SmartScreen 提示，SHA-256 仅用于校验产物完整性。

Draft Release 仅会在精确 tag/版本验证、Debug 与 Release 检查、Quality、D3D11VA 硬件和
性能门禁、1.2.0 升级、packaged smoke 与 shutdown soak 全部在目标 release SHA 上通过后创建。
