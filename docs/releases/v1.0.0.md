# DualVideoStudio 1.0.0

DualVideoStudio 1.0.0 是 2～3 路 VFI 专用视频比较器的首个正式稳定版。本版本发布自
`main`，项目版本、Windows 包元数据、Git 标签和 Release 资产统一为 `1.0.0`。

## 主要能力

- 支持 2 路或 3 路视频的帧精确同步审查，并明确选择 canonical/reference source。
- 每次显示均发布完整、原子的 `FrameSet`，不会混合不同请求或不同时间位置的帧。
- 支持任意两路差分、全局偏移估计、带状序列对齐、掉帧/重复帧检测和手动锚点。
- 支持同步缩放/平移、ROI、阈值遮罩、四面板分析网格和 exact-plane difference。
- 支持 8/10-bit、P010、YUV422/YUV444/RGB 视觉归一化、rotation、SAR 和颜色元数据。
- D3D11VA 与 Qt 共用 D3D11 设备，NV12/P010 decoder surface 可直接进入 renderer。
- Project schema v3 保存来源、offset、anchors 和 view state，并支持 open/save/relink。
- Windows x64 ZIP 和 MSI 捆绑固定版本的 FFmpeg/ffprobe 8.1.2、Qt 运行时、
  provenance 及第三方许可文本。

## 当前边界

- 性能门禁素材不进入 Git 仓库，由 self-hosted runner 的
  `DVS_PERFORMANCE_FIXTURE_ROOT` 提供。
- presentation index 和 signature cache 当前为进程内复用。
- 发布资产未进行 Authenticode 代码签名；Windows 可能显示 SmartScreen 提示，
  请使用 Release 提供的 SHA-256 文件核验下载。
