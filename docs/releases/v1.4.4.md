# VCStation 1.4.4

VCStation 1.4.4 是稳定性修复版本，统一了审查菜单和来源操作语义，并收紧异步帧请求的
完成合同。

---

## 主要修复

- 所有主菜单、二级菜单、右键菜单和 Source 菜单都使用同一套非 Native、完全不透明的
  QML Popup 与菜单项样式；菜单打开时不会把 Space、A/D 或 Tab 传递给媒体快捷键。
- Reference 标记现在是只读 `R` badge；每个多路视频都有独立的 `…` 操作菜单。切换
  Reference 和删除视频按规范化路径、文件大小和修改时间标识具体来源，排队与失败回滚
  不会作用到错误会话。
- MultiSourceFrameProvider 在发布 `RequestSucceeded` 前退休请求自有的 FrameSet 和
  FrameBudget 资源。发布工作流在 4 CPU、BelowNormal 配置下连续运行该回归场景 100 次。
- 删除不属于当前审查产品的 Clip/Export 错误文案分支，并验证全部现有 MediaError 稳定 ID
  仍有用户可见文案。

---

## 发布范围

VCStation 支持 H.264、HEVC、MPEG-4 Part 2 与 SDR 视频，不播放音频轨道。发布产物为
Windows x64 ZIP、MSI 与 SHA256SUMS。本版本保持未签名：Windows 可能显示 Unknown
Publisher 或 SmartScreen 提示，SHA-256 仅用于校验产物完整性。

Draft Release 仅会在精确 tag/版本验证、Debug 与 Release 检查、Quality、D3D11VA 硬件和
性能门禁、1.2.0 升级、packaged smoke、shutdown soak，以及 FrameProvider 100 次资源退休
压力测试全部在目标 release SHA 上通过后创建。
